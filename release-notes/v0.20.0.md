# v0.20.0 — guides you can use mid-game: condensed notes, extracted builds, topic summaries

**Sancho Panza · Age of Empires 2 Fan Companion v0.20.0** — AI coach for Age of Empires II: DE.

### Downloads
- **Windows**: `SanchoPanza-0.20.0-windows-x64.zip` → unzip → double-click `Instalar.bat`.
- **Mac with Apple chip (M1–M4)**: `SanchoPanza-0.20.0-mac-arm64.zip` · **Mac with Intel**: `SanchoPanza-0.20.0-mac-x64.zip` → drag to Applications → first launch: System Settings → Privacy & Security → "Open Anyway".
- **Android / iPhone / any browser**: https://mdatas.github.io/sancho-panza/ → "Add to Home screen".

### Changes
- **Every guide condensed for the game**: each of the 636 video/guide notes now opens with an "En la partida" block (3–6 lines with the numbers that matter; VIGENCIA corrections already applied); the full note is folded underneath.
- **Step-by-step builds extracted from the guides**: 25 new builds in the panel (F7/F8, build clock), each step carrying the sentence of the note that supports it; a build was kept only when every quote was found verbatim in the note, so nothing is invented. Tagged "extraído" in the list; the note shows "▶ Cargar pasos".
- **Topic summaries** (Guide → Temas): 24 topics — scouts, archers, men-at-arms/drush, fast castle & boom, knights, tower rush, TC/castle drop, monks, siege, water, elephants, villager rush, Dark Age economy, defending rushes, walls, scouting, compositions, closed maps, Nomad, team games, late game, micro, mistakes by ELO, macro benchmarks — each with the essentials, how it is done, **alternatives where the guides disagree**, typical mistakes and counters; every line cites its guide. The coach uses them for general questions.
- Settings tab moved to the right of Guía.

Generated with the project's own notes as the only source (`tools/condense.js`, `tools/themes.js`); the cost of the one-off run was about US$8.5 in API calls.
