# v0.17.0 — medieval look, icons in the guide

**Sancho Panza · Age of Empires 2 Fan Companion v0.17.0** — AI coach for Age of Empires II: DE.

### Downloads
- **Windows**: `SanchoPanza-0.17.0-windows-x64.zip` → unzip → double-click `Instalar.bat`.
- **Mac with Apple chip (M1–M4)**: `SanchoPanza-0.17.0-mac-arm64.zip` · **Mac with Intel**: `SanchoPanza-0.17.0-mac-x64.zip` → drag to Applications → first launch: System Settings → Privacy & Security → "Open Anyway".
- **Android / iPhone / any browser**: https://mdatas.github.io/sancho-panza/ → "Add to Home screen".

### Changes
- New look: dark oak and leather, gilt accents, heraldic shields for the 4 v 4 bar (blue = your side, red = enemies), Cinzel and Alegreya typefaces (bundled, SIL Open Font License).
- Guide: icons for unique technologies and for everything a civ lacks (units and techs), emblems for each map type, "yours / enemy" badges translated.
- Web version on computers: wider layout; the guide uses the full width; the Guide tab is the same size as the other tabs.
