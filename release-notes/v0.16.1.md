# v0.16.1 — Windows, Mac, Web, 7 languages

**Sancho Panza · AOE2 Squier v0.16.1** — AI coach for Age of Empires II: DE.

### Downloads
- **Windows**: `SanchoPanza-0.16.1-windows-x64.zip` → unzip → double-click `Instalar.bat` (downloads the Electron runtime once and checks its SHA-256).
- **Mac with Apple chip (M1–M4)**: `SanchoPanza-0.16.1-mac-arm64.zip` · **Mac with Intel**: `SanchoPanza-0.16.1-mac-x64.zip` → drag to Applications → first launch: System Settings → Privacy & Security → "Open Anyway" (not notarised by Apple).
- **Android / iPhone / any browser**: https://mdatas.github.io/sancho-panza/ → "Add to Home screen".

### Changes
- The Windows download is now named `SanchoPanza-…-windows-x64.zip` (same contents as before).
- Visual guide translated into the 7 languages; civ/map profiles and notes get a 🌐 Translate button (uses your own AI key, cached on your device). Same button in the build-order reader.
