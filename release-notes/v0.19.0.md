# v0.19.0 — faster, cheaper, clearer: the review release

**Sancho Panza · Age of Empires 2 Fan Companion v0.19.0** — AI coach for Age of Empires II: DE.

### Downloads
- **Windows**: `SanchoPanza-0.19.0-windows-x64.zip` → unzip → double-click `Instalar.bat`.
- **Mac with Apple chip (M1–M4)**: `SanchoPanza-0.19.0-mac-arm64.zip` · **Mac with Intel**: `SanchoPanza-0.19.0-mac-x64.zip` → drag to Applications → first launch: System Settings → Privacy & Security → "Open Anyway".
- **Android / iPhone / any browser**: https://mdatas.github.io/sancho-panza/ → "Add to Home screen".

### Faster and cheaper answers
- The answer is **streamed** while the model writes it; the 3-line summary is read aloud as soon as it is complete.
- The match-fact extraction runs **in parallel** with the answer instead of before it.
- **Pre-computed counters** for the enemy army you registered ("me tira mangudai") and team counters go into the prompt, so most questions need fewer tool rounds.
- **Prompt cache on by default**: fixed rules and per-question notes in separate cached blocks; about US$0.03–0.05 per question with Claude Sonnet (shown under each answer). History kept to 6 exchanges.

### Better retrieval
- New note search: BM25 inverted index with bilingual stemming and alias folding (Spanish and English spellings are one term); milliseconds per query instead of a regex scan.
- The extraction step also produces Spanish/English keywords, so questions in any UI language find the Spanish notes.
- The AI's `search_notes` tool is told to query with keywords mixing Spanish terms and English game names.

### Build orders and data
- **Build clock** (▶ in the panel): steps advance by their time stamp; if you move a step by hand it says how many seconds ahead/behind you are.
- A generic build shows the start/eco bonuses of the civ you registered.
- **Benchmarks tool** for the coach: graded timings (A+ … E) for the standard builds from Cicero's build-order reference (sourced in the notes).
- The eco gather rates say which patch they were reviewed against; the win-rate table is picked by patch number (no more hardcoded file name).

### Guide and UX
- One search box in the Guide for civs, maps, units and notes; a link to the full tech tree (aoe2techtree) on every civ; the counters calculator states its assumptions.
- Welcome popup with two clear paths — "Use without AI for now" or configure a key — with the real cost per question and the borderless-window tip.
- Quick-action chips (counters, build, guide, new game, help) in the welcome and after `/new`.
- Settings regrouped: everything unusual under **Advanced**; new toggles for streaming and the build clock; a warning when a hotkey collides with a default AoE2 DE key (F3 pause, F10 menu, F11 stats, F12 screenshot).
- Smallest texts raised to 11–12 px; tabs never clip on narrow windows; the TTS reads "+22" in the voice's language and the Windows system voice follows the UI language.
- In-app "About" with licenses and the Microsoft Game Content Usage Rules notice.

### Fixes (robustness)
- After a game-data sync the coach kept answering from the old dataset (`brain.gd` was never updated) — fixed; caches are dropped on every reload.
- `settings.json` is written atomically (temp file + rename) and no longer on every resize/move or keystroke: a crash can no longer wipe your API key and settings. A corrupt file is kept aside as `settings.json.corrupt`.
- The patch-watch state no longer lives inside the game-data cache (which the sync wipes); it is migrated automatically.
- A corrupt cached dataset falls back to the bundled one instead of preventing the app from starting.
- Questions are serialised; "Test connection" can no longer interleave with a running question.
- `/civ ma` no longer silently picks Magyars: a civ prefix must be unambiguous.
- The match state is restored when you reopen the app within 3 hours (same game).
- Web: data files are versioned and split (core / builds / notes); a new release can no longer run on stale cached data; the notes load in parallel; JSON minified (bundle 11.5 → 9 MB raw, ~1.7 MB gzip).

### Security and privacy
- An API key is never sent in clear text to a public `http://` host (always enforced, not only in the privacy mode).
- `settings.set` accepts only known keys with the right types.
- The guide's `postMessage` channel is restricted to the app's own origin.
- Patch notes are read only from `ageofempires.com` links and stored as plain data (not as instructions).
- When the system cannot encrypt the key, the UI says so instead of claiming it is encrypted.
- Conversation logs are deleted after 30 days by default; the privacy text now lists every host the app contacts.
- Electron fuses: the installed app can no longer be used as a plain Node runtime (`ELECTRON_RUN_AS_NODE`), nor driven with `NODE_OPTIONS` / `--inspect` (Windows installer, with a start-up check and rollback; Mac packages).
- CI: lint, unit tests, the headless Electron smoke test, the web build and its Playwright test run on every release; actions pinned to commit SHAs; only the publish job can write.

### Code
- One `src/main/api.js` behind both the desktop IPC and the web `window.coach` (no more duplicated handlers); the smoke test moved out of the packaged app; ESLint + Prettier; magic numbers named; strings outside the language tables routed through i18n; `benchmarks.json` generated by `tools/benchmarks.py`.
