# v0.21.1 — installer that shows its progress and never hangs, uninstaller, screenshots

**Sancho Panza · Age of Empires 2 Fan Companion v0.21.1** — AI coach for Age of Empires II: DE.

### Downloads
- **Windows**: `SanchoPanza-0.21.1-windows-x64.zip` → unzip → double-click `Instalar.bat`.
- **Mac with Apple chip (M1–M4)**: `SanchoPanza-0.21.1-mac-arm64.zip` · **Mac with Intel**: `SanchoPanza-0.21.1-mac-x64.zip` → drag to Applications → first launch: System Settings → Privacy & Security → "Open Anyway".
- **Android / iPhone / any browser**: https://mdatas.github.io/sancho-panza/ → "Add to Home screen".

### Changes
- **Windows installer**: every step prints what it does and when (unpacking the 170 MB runtime takes a couple of minutes while the antivirus scans it — it looked stuck before); the start-up probe has a 30 s limit, so nothing waits forever. It detects the installed version, builds the new one in a separate folder and swaps it in (settings, API key and logs stay in `%APPDATA%\AoE2 Coach`); the app is registered in **Windows → Installed apps** with its uninstaller; a Start Menu shortcut is added. Accented text in the console no longer shows as mojibake.
- **Uninstaller**: Settings → Data → *Uninstall…* inside the app, Windows → Installed apps, or `Desinstalar.bat` (in the zip and in the app folder). It closes the app, removes the program, the downloaded runtime, the shortcuts and the registry entry, and asks whether to delete your settings and API key too. On Mac the button shows the app to drag to the Trash and can delete the data folder.
- **README**: screenshots of every part of the app (chat, team counters, condensed guides, overlay, guide pages, build orders, the four looks, the phone).
