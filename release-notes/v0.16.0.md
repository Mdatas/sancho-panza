# v0.16.0 — Windows, Mac, Web, 7 languages

**Sancho Panza · AOE2 Squier v0.16.0** — AI coach for Age of Empires II: DE.

### Downloads
- **Windows**: `AoE2Coach-0.16.0-setup.zip` → unzip → double-click `Instalar.bat` (downloads the Electron runtime once and checks its SHA-256).
- **Mac with Apple chip (M1–M4)**: `SanchoPanza-0.16.0-mac-arm64.zip` · **Mac with Intel**: `SanchoPanza-0.16.0-mac-x64.zip` → drag to Applications → first launch: System Settings → Privacy & Security → "Open Anyway" (not notarised by Apple).
- **Android / iPhone / any browser**: https://mdatas.github.io/sancho-panza/ → "Add to Home screen".
