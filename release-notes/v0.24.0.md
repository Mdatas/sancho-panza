# v0.24.0 — back to the full AI coach (the v0.21.1 app)

**Sancho Panza · Age of Empires 2 Fan Companion v0.24.0** — AI coach for Age of Empires II: DE.

### Downloads
- **Windows**: `SanchoPanza-0.24.0-windows-x64.zip` → unzip → double-click `Instalar.bat` (replaces the previous version; settings and key stay).
- **Mac with Apple chip (M1–M4)**: `SanchoPanza-0.24.0-mac-arm64.zip` · **Mac with Intel**: `SanchoPanza-0.24.0-mac-x64.zip` → drag to Applications → first launch: System Settings → Privacy & Security → "Open Anyway".
- **Android / iPhone / any browser**: https://mdatas.github.io/sancho-panza/ → "Add to Home screen".

### Changes
- **Rollback to the v0.21.1 app.** Every question is answered by the AI again (3-line summary + detail, read aloud), with the Tavern look, the 4 v 4 bar, build orders, the guide and the step-by-step installer of v0.21.1. The match sheet, the local answer mode and the screen reading (OCR) of versions 0.22–0.23 are **out of the app**; that work is kept on the [`local-ocr`](https://github.com/Mdatas/sancho-panza/tree/local-ocr) branch to pick up later.
- Installing over 0.22/0.23 works as usual: key, settings and logs stay; the settings those versions added are ignored.
