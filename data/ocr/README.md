# data/ocr

`eng.traineddata` — Tesseract 4/5 "fast" English model (tessdata_fast, Apache-2.0), used by the local screen reader
(src/main/ocr/local.js) to read the digits of the game's resource bar on this PC. Source:
https://github.com/tesseract-ocr/tessdata_fast — only digits, "/", ":" and the age names are ever asked of it.
